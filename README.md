# Power BI Projects

## Repository Overview

This repository contains two Power BI project folders with dashboards and reports:

- `Project-Dengue` — dengue cases and medicine sales analysis
- `Project-Sales Data` — sales trend, product performance, promotions, and order-level analysis

Each project folder includes a Power BI report and a dedicated `README.md` with details from the corresponding report.

## Project Summaries

### Project - Dengue Data
- Focuses on global dengue case tracking and dengue-related medicine sales.
- Key metrics include total cases, active cases, critical cases, and death cases.
- Includes gender and country breakdowns, plus cumulative case trends by fiscal month.
- Medicine sales section covers product sales, monthly sales, and sales by country grouping.

### Project - Sales Data
- Focuses on commercial sales performance and customer ordering behavior.
- Includes multi-year sales trends, profit vs net sales comparisons, and promotion discount analysis.
- Provides city-level sales insights and top/bottom product rankings by sales, quantity, and profit.
- Includes summary metrics for total sales, total profit, and total quantity sold, plus a detailed order-level data table.

## How to Use

1. Open the desired project folder in Power BI Desktop.
2. Review the project-specific README for the report details and data highlights.
3. Analyze the dashboard visuals and filters for deeper insights.

## Notes

- All reports are built in Power BI Desktop.
- The root README is a high-level summary; for full details see the README inside each project folder.
